# PromptMeter Trademark & Branding Policy

The AGPL-3.0 license in [LICENSE](./LICENSE) covers the PromptMeter **source code**. It does **not** grant any rights to the **"PromptMeter" name, logo, or branding** ("the Marks").

## What this means

- **You may** use, modify, and redistribute the source code under the terms of the AGPL-3.0, including running your own instance.
- **You may** truthfully state that your project is "built on PromptMeter" or "a fork of PromptMeter."
- **You may not** use the PromptMeter name or logo as the name of your own product, service, or fork in a way that suggests it is the official PromptMeter or is endorsed by the maintainer.
- **You may not** use the Marks for a hosted/commercial service in a way likely to cause confusion about the source or sponsorship of that service.

If you distribute a modified version, please give it a distinct name so users can tell it apart from the official project.

## Why this is separate from the code license

Open-source code licenses (including the AGPL) intentionally do not license trademarks. Keeping the name protected separately means anyone can use and build on the code, while the *identity* of the official project stays clear and trustworthy — which matters most for a tool whose value is being a credible source of cost estimates.

## Questions / permission requests

For uses not covered above — partnerships, endorsements, or commercial use of the name — contact the maintainer.
